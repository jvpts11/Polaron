# THE STANDARD LIBRARY'S OWN ADVICE, COUNTED. A ratchet: these may go DOWN, never up.
#
# Every number here is a place the library does not follow the language it defines, found by the
# rule beside it. They are not noise and they are not exemptions -- they are the debt the advice
# discovered, written down so that it cannot grow quietly and so that paying it off is visible.
#
# The rule when a count rises: fix the code, or write `[Allow(code:, why:)]` where the shape is
# deliberate. Raising the number is not one of the options.
# The rule when a count falls: lower it here, in the same change. A ratchet that is not tightened
# lets the same debt come back.
#
# A count may also fall because the RULE was wrong, and nine of them were: advice about a `*` that
# came from a type argument rather than from the author's text, about a boolean-and-a-pointer that
# nothing writes through, about a channel whose own class drains it two lines below, about a
# per-element bounds check the compiler already versions the loop to avoid, about `private` on a
# field nothing can write, about a transformer for a class with no subject to apply it, about a
# `move` on an integer, about a scan of a collection the loop itself makes, and about a guard that
# names neither the receiver nor any argument of the call it precedes. A rule that reports a cost
# nobody pays teaches its reader to skip the whole catalogue, so those are defects in the same sense
# as the debt is -- and every one of them gained a sample fixing BOTH answers, so a narrowing cannot
# quietly become a silence with only this number to notice.
#
# `polc --check tests/samples/hello_world.pol --lint-prelude` prints them.
#
# NOT THE WHOLE LIBRARY. A generic is analysed where it is INSTANTIATED, so what this counts is what
# `hello_world.pol` happens to instantiate. Across all 678 samples the union is 1653 against the 1541
# this counted the day it was written, and two files -- `Arena.pol` and `Compare.pol`, which are
# generic end to end -- were not covered by a single line of it.

# WHAT THE TWO BIG NUMBERS ARE, since they are the ones a reader will ask about.
#
# 0B40 is 180 loops whose index the range analysis cannot relate to the array's length, and every
# one of them is a loop `hoistBoundsChecks` refuses -- a call in the body, a nested loop, an index
# the versioner cannot prove affine. The COST is real and measured: the check stays. What is not
# available is the fix the catalogue names, because the bound is genuinely a third quantity: a flat
# matrix indexed `row * n + col`, a stack pointer, a message schedule of eighty words. Paying it off
# means slices or invariants through the numeric and crypto code, which is a piece of work and not
# a pass.
#
# 0B24 is 31 signatures taking three or more of one primitive, where any order compiles. That is a
# real hazard and the fix is a `newtype` or a slice per concept -- an API change across `Time`,
# `Tls` and `Math`, again a piece of work rather than a pass.
